How It Works
Three simple steps — entirely in your browser, nothing uploaded to a server.
1

Choose Input

Upload a .docx / .xlsx / .csv file via drag-and-drop, or switch to the built-in rich text editor.

2

Auto Convert

15 transformation rules run instantly — headings, bold detection, tables, phone links, strikethrough removal, link nesting, URL fixing, syntax repair and more.

3

Copy or Download

Switch between Preview and HTML code tabs. Copy to clipboard or download as a .txt file.

4

Verify with Tests

47 automated checks run on every conversion. Open the built-in test panel or visit tests.html for the standalone suite — download a full HTML report.
