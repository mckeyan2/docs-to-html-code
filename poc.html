Key Features
Everything you need for clean, production-ready HTML output.
🔒

100% Browser-Side

No files ever leave your device. All conversion happens locally using Mammoth.js and SheetJS.

✏️

Rich Text Editor

Full toolbar: headings, bold, italic, underline, lists, alignment, indent, links, and more.

📊

Excel & CSV Support

Every sheet becomes a labelled HTML table. Supports .xlsx, .xls, and .csv formats.

🏷️

Semantic Tables

Bold first rows automatically become <th scope="col"> with proper <thead> and <tbody>.

📋

Copy & Download

One-click copy to clipboard or download as .txt. Preview rendered output alongside the code.

🌙

Dark Mode

Automatically adapts to your system's light or dark preference using CSS custom properties.

🧪

Built-in Test Suite

21 automated checks validate every conversion. Failed checks report the exact line number for fast debugging.
